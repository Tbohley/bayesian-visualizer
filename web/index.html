Thanks for checking out this demo!

This prototype research tool allows for intuitive construction and analysis of Bayesian models without the need for complex libraries and data wrangling.

For a quick introduction, load a preset, compile the graph, and run inference. One of the weight variables posterior histogram will open automatically when warmup rounds are done. This lets you skip construction and dive into the analysis features built into the prototype.

Creating nodes and links

Clicking the canvas will spawn a node of the currently selected type.

If you want to use one node's output as a parameter for another node, hold shift and click both nodes to create a link between them.

As a reminder:

Editing node parameters

Clicking on a node will select it and open up a sidebar where parameters can be set to any incoming links.

Incoming links are mapped to unassigned parameters by default on creation.


Node arithmetic

To represent non-trivial relationships between

Compilation and error-checking

Compiling your graph will make pop-up appear if any nodes have unfilled parameters, a cycle exists, or there are any other errors preventing the backend from creating a valid Fugue model.

Running inference

The inference menu will be accessible once the graph has been compiled. If you want the same results every time, use the box to set a custom seed. 

Note that once warmup rounds have been completed, you can begin to view posterior samples by inspecting nodes.

Viewing results

In an individual node's posterior histogram, mouse brushing will create a persistent selection containing the samples in those bins.

That selection will be saved in the background so that you can see how it corresponds to other posterior distributions.

Joint Posterior Distributions

When viewing a posterior distribution, hold shift and click a second node to open up a new side panel showing the two variables' joint posterior distribution.

Lassoing this grid will create a selection that works in the same way as those created by brushing.
